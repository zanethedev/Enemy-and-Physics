# Enemy-and-Physics
## What it is
This is an extremely basic game where you try to avoid the enemy. The enemy can jump and move, so try your hardest to not get caught!

## How to run it:
- Download as ZIP
- Launch Godot
- Click the "Import" button
- Select the file
- Click "Open", then click "Import & Edit"

The project should now open in Godot! You can run it by clicking on the Play button in the top right!
